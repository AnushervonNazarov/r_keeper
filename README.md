## Project Description

**r_keeper** is a restaurant management system developed using Go and the Gin framework. The application provides functionality for waiters and administrators, including order management, table reservations, menu management, table management, and report generation.

## Features

- **Authentication and authentication:** Login via JWT tokens.
- **Order management:** Create, view, update, and delete orders.
- **Table reservations:** Book and manage tables in the restaurant.
- **Menu management:** Add, edit, and delete dishes on the menu.
- **Table management:** Add, edit, and delete tables.
- **Reports:** Generate reports for administrators.
